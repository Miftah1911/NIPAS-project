The Problem · Bangladesh

Bangladeshi smallholders face five compounding crises

🚱

Groundwater depletion

Northern districts (Rajshahi, Rangpur, Dinajpur) sit over aquifers being pumped dry. Water tables drop meters per decade. Tube wells now go 300+ feet deep.

💸

Over-fertilization & chemical waste

Farmers spend 30–40% of income on chemicals. Most is broadcast — where 60–70% never reaches the plant. Runoff contaminates canals and kills soil biology.

🌱

Root zone damage from manual testing

Traditional digging cuts through fine root hairs that absorb nutrients. Every cut is an infection entry point.

🍂

Diseases spread before they're visible

By the time a farmer sees yellowing, the disease has spread. The window between invisible and unrecoverable is 3–5 days.

👴

Labor shortage & aging farmers

Average farmer is over 50; young people migrate to cities. Not enough hands to walk every field every day.

Offline-First Design

Rural villages have no reliable WiFi — so the robot doesn't need it

WiFi in Bangladeshi fields is rare. Even 4G is patchy. So we designed NIPAS to work in three modes — and the default is no network at all.

📴
◈ Mode 01 · Default

Fully Offline

Robot drives, scans, and sprays autonomously. No network required. Every reading is buffered to ESP32 flash memory — up to 45 days of data.

🔄
◈ Mode 02 · Auto

Local Sync

When the robot reaches any network — home WiFi, phone hotspot, or 4G — the buffer auto-flushes to the dashboard. 1,000 readings upload in ~3 seconds.

📡
◈ Mode 03 · Bonus

Live Stream

If the farmer has a phone hotspot on, they can watch the mission in real time. This is a bonus — not a requirement.

The architectural principle: the network is a nice-to-have, not a dependency. Core autonomy never requires connectivity.

Autonomy Factors

What makes the robot run on its own

📏

Odometry via Encoders

Distance tracked by wheel rotations. Every 20 ticks ≈ 20 cm.

  • Knows exact row position
  • Triggers scan at correct spacing
  • Detects row end without GPS
🚧

Reactive Obstacle Avoidance

Ultrasonic continuously samples the path ahead.

  • Back up + turn sequence
  • Retries after obstacle clears
  • Escalates to ERROR if stuck
🔄

Row-End Detection

Encoder ticks compared against configured row length.

  • Auto turn on reaching end
  • Row counter increments
  • Field finish when all rows done
🎯

Adaptive Spray Dosing

Spray duration computed from infection severity.

  • Healthy → 0 ms
  • Mild → 800 ms
  • Severe → up to 2500 ms
🔗

UART CAM Handshake

The CAM responds within a 3-second timeout.

  • Never blocks indefinitely
  • Fails safe on CAM crash
  • Retries next plant
📴

Offline-First Buffer

Every reading stored in flash when network absent.

  • ~45 days storage capacity
  • Auto-flush when reconnected
  • Survives power cycles

Honest Assessment

What we haven't solved yet

Being honest about limitations separates a real engineering project from a hobby demo.

📐

Approximate 180° turns

Timed, not gyro-corrected. Small drift accumulates over long rows.

📷

HSV is sunlight-sensitive

Cloudy days shift HSV values. Calibration step or AWB-locked camera would improve robustness.

🌾

No weed vs crop distinction

Camera can't tell a chili plant from a similar-hue weed. Needs shape analysis or ML model.

🔋

Runtime limited by pump

Pump draws 1–2 A. Battery bank gives 2–3 hours of continuous operation.

🧪

Single-tank chemical

Mixing fertilizer + fungicide needs a second tank + pump.

📡

Live stream requires network

Robot works offline, but live telemetry to the dashboard needs connectivity. Data buffers to flash and syncs when available.

Future Scope · 1

Full custom PCB with everything on one board

Design target, not a shipping product today.

◈ Commercial Mid-Tier · Now
Terminal Shield
ESP32 sits on a custom terminal shield. External modules connect via screw terminals — no jumper wires.
  • Custom terminal shield PCB
  • External L298N motor driver
  • External relay + power modules
  • ≈৳7,180 total manufacturing cost
  • Field-ready but modular
  • Status: Design complete · not yet assembled
◈ Next Generation
Full Integrated PCB
A single PCB replaces terminal shield, external motor driver, and power module.
  • Single ESP32-S3 with camera interface
  • Onboard DRV8833 motor driver
  • Integrated buck + TP4056 Li-ion charger
  • Reduces wiring failures by ~70–80%
  • ≈৳1,800 per PCB at 100-unit scale (board only)
  • Status: Concept stage · 6-month roadmap

Note: ৳1,800 covers the PCB alone. A complete next-gen robot at scale would still cost ~৳6,500–7,500. The gain is reliability, not a dramatic price drop.
